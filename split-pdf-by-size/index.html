When is splitting by size useful?

Email providers cap attachments (often 10–25 MB), upload forms reject big files, and messaging apps choke on large documents. Splitting by size guarantees every part fits the limit — no guessing how many pages make 5 MB. It also helps when sharing a long report in instalments or archiving chapters separately. Because each part keeps the original pages' fonts and images, quality is identical to the source.

What exactly does Split PDF by Size do?

It measures each page on its own, then groups pages so every part stays under the size limit you set — a preset or any custom value from 0.1 to 100 MB. A single page that is bigger than your limit on its own cannot be split further, so it is kept as its own file and flagged with a warning. Every part keeps the original pages, fonts and images exactly, and you can download parts one by one or all together as a ZIP.

Related tools: Split PDF splits by page ranges instead of size; Split PDF by Bookmarks splits at chapters; Compress PDF shrinks a file before you split it.

Frequently asked questions

How do I split a PDF by size?

Upload your PDF, pick a maximum size per part (for example 5 MB), and click Split. The tool groups pages so every output file stays under your limit, then lets you download each part or all parts as one ZIP.

What happens if a single page is bigger than my size limit?

A single page cannot be split further without recompressing it, so it is kept as its own file and flagged with a warning. Use the Compress PDF tool first if you need that page smaller.

Are the split files smaller than the original?

Yes. Each file contains just its own pages, so individual files are much smaller than the original — handy for email attachments with size limits.

Is my PDF uploaded anywhere?

No. The tool runs entirely in your browser with pdf-lib. Your file never leaves your device.

Can I split by a custom size, not just presets?

Yes. Enter any size in MB (from 0.1 MB up to 100 MB) in the custom field, or use the 1 MB, 2 MB, 5 MB, 10 MB and 25 MB presets.

Can I download only one part?

Yes. Every part in the results table has its own Download button, so you can save just the parts you need instead of the whole ZIP.

Do the parts keep the original quality?

Yes. Pages are copied exactly as they are — no recompression, no rasterising — so fonts, images and text in each part are identical to the source.

What size limits can I set?

The presets are 1, 2, 5, 10, and 25 MB, and the custom field takes any size from 0.1 MB up to 100 MB. Pick the limit your email provider or upload form actually enforces.

How do I download the parts?

Download each part individually, or grab everything at once as one ZIP file. Each part contains consecutive pages, in document order.

What if a single page is bigger than my limit?

A single page cannot be split further without recompressing it, so it is kept as its own file and flagged with a warning. Run that page through the Compress PDF tool first if you need it smaller.

When to use it

  • Split a 40 MB report into parts under a 25 MB email attachment cap.
  • Break a long manual into 5 MB chunks for a messaging app.
  • Share a big document in instalments with a client on a slow connection.
