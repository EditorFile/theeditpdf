When is splitting by bookmarks useful?

Long documents — ebooks, reports, manuals, course material — are usually organised into chapters, and those chapters are stored as bookmarks. Splitting by bookmarks turns one big file into clean, sensibly named chapter files without you having to look up page numbers. A teacher can hand out one chapter at a time, a team can share just the relevant section of a report, and an ebook reader can keep each chapter as its own file. Because each part keeps the original pages' fonts and images, quality is identical to the source.

What exactly does Split PDF by Bookmarks do?

Split PDF by Bookmarks reads the table of contents stored in your PDF and cuts the file at each bookmark, so every chapter or section becomes its own PDF named after its bookmark. It only works on PDFs that contain bookmarks, and scanned files usually have none. Pages before the first bookmark are kept as a separate first file.

Related tools: Split PDF splits by page ranges instead of bookmarks; Split PDF by Size splits a large file into parts under a size limit; Create Bookmarks adds a table of contents to a PDF that has none.

Frequently asked questions

How do I split a PDF by bookmarks?

Upload your PDF and the tool reads its bookmarks (table of contents). Choose which bookmark level to split at — for example top-level chapters only — then click Split. Each bookmark becomes its own PDF file, named after the bookmark, and you can download them individually or all at once as a ZIP.

What if my PDF has no bookmarks?

Then there is nothing to split by. The tool tells you so clearly instead of failing silently. Use Split PDF by Size or Extract Pages instead, or add bookmarks to the PDF first (for example in a desktop PDF editor) and try again.

What happens to pages before the first bookmark?

Pages before the first split bookmark (for example a cover or preface) are kept together as their own first file, so no pages are ever lost.

Are the output files named after the bookmarks?

Yes. Each part is named after its bookmark, for example "Chapter 1 - Introduction.pdf". Characters that are not allowed in file names are replaced automatically.

Which bookmark level should I choose?

Top level only splits at chapters, which suits most ebooks and reports. Up to level 2 also splits at the sections inside each chapter, and All levels splits at every bookmark, giving you more, smaller files. Levels deeper than the bookmarks in your PDF are disabled, so you can only pick levels that exist.

What happens to bookmarks that have no page?

Some bookmarks point to a website or a broken link instead of a page. Those cannot be split on, so the tool skips them and tells you how many were skipped. The rest of the document still splits normally.

What if two bookmarks start on the same page?

Only the first bookmark on that page becomes a split point; the second is ignored. That stops the tool creating an empty file between two bookmarks that share a page.

Is my PDF uploaded anywhere?

No. The tool runs entirely in your browser with pdf.js and pdf-lib. Your file never leaves your device.

Which bookmark levels can I split at?

Top level only (chapters), up to level 2 (chapters + sections), up to level 3, or all levels. Pick the level that matches how finely you want the document divided.

Can I split an ebook into chapters?

Yes — that is the main use. Long documents like ebooks, reports, manuals, and course material are organised into chapters stored as bookmarks, and each one becomes its own sensibly named file.

Do I need to know the page numbers?

No. The bookmarks define the split points, so you never have to look up page numbers — the tool reads the table of contents and splits there.

When to use it

  • Hand out one chapter of a course book at a time to students.
  • Split a 300-page manual into chapter files for a support team.
  • Break a long report into sections to email to different reviewers.
