When is splitting by text useful?

Monthly invoice runs arrive as one giant PDF — split by "Invoice No." and each invoice becomes its own file to send to the right client. The same trick separates chapters in a scanned book, sections in a long report, or individual records in a bulk export, without counting pages by hand.

Frequently asked questions

How does split by text work?

The tool reads the text of every page and starts a new file at each page where your marker text appears. The page with the marker becomes the first page of the new part.

Can I use a pattern instead of exact text?

Yes. Turn on 'Regular expression' and enter a pattern — for example Invoice\s+No\.\s*\d+ matches 'Invoice No. 1042'. An invalid pattern shows an error before anything is split.

What if the marker never appears?

You get a single file — the whole document — and a note saying no page matched. Check the spelling or try a shorter marker.

Does it work on scanned PDFs?

Only if the pages have a text layer. Pure image scans contain no text to match — run the file through the OCR PDF tool first, then split the result.

Is the marker text case-sensitive?

No, matching ignores case by default. Turn on 'Case sensitive' if 'Invoice' and 'invoice' must be treated differently.

Is my PDF uploaded anywhere?

No. Splitting runs entirely in your browser with pdf.js and pdf-lib. Your file never leaves your device.
